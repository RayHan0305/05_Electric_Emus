# The CMEE Groupwork Repository of Electric_Emus

**Welcome to our Repository !!!**
This repository contains all CMEECourseWork and group practices for the Living Planet with Computational Methods in Ecology and Evolution (CMEE) module.

Each weekly folder includes its own `README.md` file, describing that week’s objectives, scripts, and key learning outcomes.

## week3
Week 3 focuses on core Python-based biological computing tasks. It consists of three Python-based practical tasks: two DNA sequence alignment exercises and one biological data filtering exercise (oak species). 

## week4
Week 4 focuses on data analysis using R. The tasks include local polynomial regression analysis and time series autocorrelation analysis based on real-world ecological and climate datasets.
